# 집지니 마케팅 팀 (2026-11-28 대표 지시: 100% 자동 · 훅킹 · 자극적 · 초간단)

흐름 — 사람 손 없음:
1. 저장소 최신으로: `git pull`.
2. **소재** jj-scout: `python3 tools/mk/scout.py` → mk/facts.json.
3. **기획** jj-strategist: 다음 월요일~일요일 7편(19:30). 인자가 주제면 그 주제 위주.
4. **글·카드** jj-writer: mk/queue/<연도>-W<주>.json 작성 → `python3 tools/mk/cards.py <파일>`.
5. **검수** jj-inspector: `python3 tools/mk/check.py <파일>` 통과 + 카드 눈 검사.
6. **내보내기**: `python3 tools/mk/build_queue.py` → mk/queue.json.
7. **올리기**: 새 갈래(mk-<주>)로 커밋 → 변경 요청 → 바로 합치기(대표 지시: 합치기 승인 기다리지 않음). 합쳐지면 jipjini.com/mk/queue.json 이 바뀌고,
   콘솔 mkImportQueue_ 가 한 시간 안에 「마케팅 자료」 시트에 「게시 예정」으로 넣고, pubTick_ 이 예약시각에 인스타그램·스레드에 올린다(게시·실패 모두 텔레그램).

지킬 선: 숫자는 facts.json 만 · 고객 개인정보·특정 단지 망신 금지 · 공사비 글은 「부가세 10% 별도」 · 이모지·영어·과장어 금지 · 당근·네이버 카페는 초안만(자동 게시 안 함).


## 0단계: 조사 먼저 (어기면 만들기 시작 금지 — 2026-11-28 대표 「전문가들 거 먼저 조사해서 탐구해서 반영하라고 했을 텐데」)
- 영상·카드·썸네일·제목·설명란·글 무엇이든, **크기와 상관없이** 만들기 전에 잘하는 사람들이 실제로 어떻게 하는지 조사한다. 「작은 덧붙임이라 생략」은 없다.
- 조사 결과는 `mk/research/<날짜>-<주제>.md` 에 「출처 · 찾은 규칙 · 그래서 우리는 이렇게」 세 칸으로 남긴다. 이 기록이 없으면 다음 단계로 넘어가지 않는다.
- 조사 범위는 **세계**로: 영어·일본어·중국어(더우인·샤오훙수)권을 함께 찾고, 한국 사례는 비교용. 분석 글만 읽지 말고 **같은 업종(인테리어·집 수리·부동산) 상위 채널 실제 사례 3~5개를 직접 열어 비교표**로 남긴다 (2026-11-28 대표 「왜 우리나라 사례만 조사하는 느낌? 글로벌 시각으로 넓게」).
- 보고할 때는 항상 「조사한 것 → 그래서 이렇게 만들었다」를 먼저 적는다.
- 여러 편을 만들 때는 틀 하나를 그대로 복제하지 않는다. 편마다 형식(갈고리 방식·색·배치·전환·소리)을 달리한다(「왜 다 똑같은 폼?」).


## AI 티 없애기 (2026-11-28 대표 「AI 티가 너무 난다」 — 조사: mk/research/2026-11-28-AI티-없애기.md, 공통 스킬 no-ai-look)
- **진짜 소재 먼저**: 촌닭건축 현장 영상·현장 사진·대표 목소리·실제 휴대폰 화면 녹화(손가락으로 넘기는 것). 합성 그림·정지 화면 확대는 거들기만.
- **자막**: 쇼츠 기본 모양(흰 글씨 + 검은 테두리, 상자 없음). 둥근 자막 상자·알약 꼬리표·「1/5」 머리말·반짝이는 테두리 금지.
- **강조**: 손으로 그은 듯한 삐뚤한 동그라미·밑줄·화살표.
- **움직임**: 컷으로 넘긴다. 통통 튀어 들어오는 효과는 영상 하나에 한 번만. 화면에 살짝 손 흔들림.
- **장식**: 이모지·3D 스티커 금지(필요하면 실제 물건 사진).
- **글**: `python3 tools/mk/aitell.py <파일>` S1 0개여야 통과. 대표 1인칭 말투, 실제 겪은 일, 문장 길이를 섞고, 구호·「A가 아니라 B」·셋 묶음·느낌표·「한눈에」 같은 꾸밈말 금지.
- **음악**: 합성 배경음 대신 유튜브 오디오 보관함 실제 곡.
- **마지막 확인**: 첫 3초를 소리 끄고 본다. 「광고 견본 같다」면 다시 만든다.


## 소재는 창고에서, 분위기에 맞춰 (2026-11-28 대표 「무료 소스를 갖고 있다가 써먹자」 「하나만 가지고 전체에 다 적용하지 말 것」)
- 만들기 전에 `tools/mk/video/assets/catalog.json`·`소재창고.md` 를 먼저 본다. 새로 구한 소재는 출처·사용 조건과 함께 거기에 적는다.
- 배경음·효과음·손 표시·화면 효과는 **그 편의 분위기와 목적**에 맞춰 고른다: 경쾌(숫자·도전) / 차분(절차·신청) / 긴장(사고·누수) / 일상 대화 / 반전. 한 곡·한 효과를 여러 편에 그대로 깔지 않는다.
- **배경음 기준(2026-11-28 대표 확정 「마음에 든다, 저장해 두고 무드마다 알아서 적용」)**: 재즈 힙합 풍 5곡을 쓴다 — 경쾌 `mood_up` / 일상 대화 `mood_talk` / 차분 `mood_calm` / 긴장 `mood_tense` / 따뜻 `mood_warm`. 만드는 법과 편성은 `tools/mk/video/tools/music/만드는법.md`. 새 분위기가 필요하면 같은 문법(9도·13도 화음, 2-5-1 진행, 16분 스윙 붐뱁 북, 통 베이스, 전기 건반, 재즈 기타·뮤트 트럼펫·색소폰)으로 `compose.py` 에 곡을 더한다. 금지: 5음 음계 가락+마림바·현 뜯기·클라리넷(「중국풍」), 건반뿐인 합성음(「저퀄리티」), 종소리·끽끽 높은 소리. 한 곡은 한 묶음에 3편까지, 같은 곡을 쓰는 편은 시작 마디를 달리한다.
- **효과 기준(2026-11-28, `mk/research/2026-11-28-효과-쓰는-법.md`)**: 소리·화면 효과는 `tools/mk/video/src/fx.ts`(효과 감독)가 정한다 — 소리는 결정 지점(첫 장면·단계 바뀜·결과·끝)에만, 휙은 큰 순간이 컷에 닿게, 결과 직전 배경음 내림 → 겹친 타격 → 살짝 올림, 결과는 마디 첫 박에, 분위기에 안 맞는 소리(차분한 편의 밈 외침 등)는 뺌, 흔들림은 사고·놀람 편에서만 짧게. 새 효과는 fx.ts 의 분위기 묶음에 더한다.
- 한 묶음(같은 주에 나가는 영상들) 안에서 같은 배경음은 3편까지, 같은 손 표시가 연달아 두 번 나오지 않게.
- 유튜브 오디오 보관함 곡은 유튜브용에만. 인스타·틱톡용은 다른 출처 곡.
