    • 13년: 2013년 처음 마주한 문제를 현장 공정 관리, 직무훈련 컨설팅, 직접 개발로 13년간 풀어 하나의 시스템으로 모았습니다 (개업 2015년 5월)
    • 문제: 인테리어 견적의 약 30%는 보이지 않는 업체 몫이고, 물량은 평수로 어림합니다
    • 해결: 반셀프 코디 + 다섯 가지 자체 제품으로 직영의 값, 턴키의 편함, 단가 100% 공개
    • 돈 버는 구조: 무료 도면 도구 → 로그인 → 상담 → 계약. 코디 계약, 현장관리, 자재 수수료 10%
    • 다음: 지금 무료 흐름 완성 → 3~6개월 업체 구독 → 내년 단지별 표준 물량 자료
