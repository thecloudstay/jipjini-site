## 전면 검토에서 찾은 문제 → 고친 것 (v3)
| 갈래 | 문제 | 고친 것 |
|---|---|---|
| 음향 | 효과음 11개가 3kHz 위 소리 40~97%(펜 6kHz 「끼익」, 칩, 동전, 휙) | 2kHz 위를 깎아 따뜻하게, 펜 소리는 낮은 「슥」 3가지로 교체. 검수에 「높은 소리 12% 이하」 추가 |
| 음향 | 배경음이 합성음, 목소리 없음 | 목소리 대본·만드는 틀 준비(깃허브에서 합성). 배경음은 유튜브 오디오 보관함 곡으로 바꿀 것(다음) |
| 영상 | 통통 튀는 글자, 반짝이는 테두리, 진행 막대, 3D 이모지 | 모두 뺌. 컷으로 넘기고 살짝 손 흔들림 |
| 영상 | 강조가 동그라미 하나뿐 | 손 표시 8가지(동그라미·화살표·밑줄·별표·형광펜·체크·꺾쇠·네모)를 장면마다 돌려 씀 |
| 자막 | 둥근 상자·알약 머리말, 아래 25%(앱 제목 자리)에 걸림 | 쇼츠 기본 자막(흰 글씨+검은 테두리), 아래-가운데(화면 62~75%)로 올리고 오른쪽 단추 자리 비움 |
| 길이 | 관리비 13.5초·경매 13.2초(15초 미만은 노출 상한) | 결과 화면을 더 오래 보여 줘 16초 이상으로 |
| 글 | 구호·「한눈에」 | 글 점검기(aitell.py) 통과 필수 |
| 자동화 | 편마다 손으로 확인 | 자동 검수(tools/qa.py: 길이·크기·음량·높은 소리·첫 화면) 통과해야 올림 |

## 아직 남은 것 (다음 차례)
1. 정지 화면 확대 → 실제 화면 녹화(손가락으로 치고 넘기는 영상)로 바꾸기: 플레이라이트 녹화 영상을 리모션에 얹는 방식
2. 목소리: 대표 목소리가 가장 좋고, 그다음이 합성 음성. 음성에 맞춰 장면 길이를 자동으로 맞추고 자막을 한두 낱말씩 띄우기
3. 배경음: 유튜브 오디오 보관함 실제 곡
4. 갈고리 3판 시험, 끝 장면이 첫 장면으로 이어지는 고리
5. 촌닭건축 현장 영상·사진을 섞기
