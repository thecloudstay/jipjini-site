# 만든 것을 스스로 평가·검증하는 체계 (2026-11-28, 대표 「네가 만든 것 자체 평가 검증하도록 시스템 구성」)

## 출처
- 「판정 모형은 신탁이 아니다」(arXiv 2609.02246): 값싼 기계 검사 → 검토 모형 → 전체 재평가 순서. 기계 탈락은 모형의 승인보다 항상 우선. 역할 분리(만드는 쪽·비평·감사), 반복 횟수 제한, 통과할 수 없는 「카나리아」 사례로 검사기 자체를 점검. 이유를 먼저 쓰게 하면 사람 판정과 더 맞음 — https://arxiv.org/abs/2609.02246
- 아라이즈 「평가기 잘 쓰는 법」: 큰 점수 눈금 대신 예/아니오 항목 여러 개, 항목은 풀어서 짧게, 만든 모형과 평가 모형을 같게 쓰지 않기(자기 편향), 사람 판정 20~100건으로 맞춰 보기 — https://arize.com/docs/ax/concepts/evaluators/evaluator-best-practices
- 고페이스리스 「숏폼 품질 점검표」: 이야기·자막·소리·화면 연속성·주장 근거·올리기 인계 6갈래. 사실·표기 실패는 차단. 판정은 통과/수정/차단 + 정확한 시각 + 가장 작은 고칠 점 — https://www.gofaceless.ai/tr/resources/short-form-video-quality-checklist
