# 효과(소리·화면)를 언제 어떻게 쓰는가 (2026-11-28, 대표 「이펙트·상황별 삽입을 많은 레퍼런스 검토 후 업그레이드」)

## 출처
- 캡컷 「패턴 끊기 기법」: 소리는 결정 지점(첫 장면·문제 드러남·전후 비교·변신)에만. 「컷마다 효과음을 넣으면 아무것도 놀랍지 않다」. 15~30초 영상이면 끊기 2~3번(시작·가운데·끝), 20초 영상은 4·9·15초쯤에서 집중이 떨어짐. 결과 직전 음악을 끊는 것도 끊기 — https://www.capcut.com/create/pattern-interrupt-technique-short-form-video
- 캡컷 「전환 유행」: 박자에 맞춘 딱 끊는 컷이 뜨고, 손으로 가리는 전환·뻔한 전후 비교는 포화. 작은 휙·딸깍으로 움직임을 받쳐 주되 많으면 번잡 — https://www.capcut.com/create/video-transition-trends-viral-short-form-edits
- 에스에프엑스엔진 「릴스 소리 편집」: 휙·라이저는 가장 큰 순간이 컷에 닿게. 큰 타격은 2~3겹(주파수 나눠서). 감정이 오르는 곳에서 음악을 2~3dB 올리고, 박자(킥·스네어)에 주요 동작을 맞춤 — https://sfxengine.com/blog/reels-audio-editing-tips
- 디스크립트 「유튜브 소리 설계」: 효과는 마지막이고 가장 적게. 만화 같은 소리는 피하고 믿을 만하고 은은하게. 곡을 그냥 반복하지 말고 순간마다 이유가 있어야 함 — https://www.descript.com/blog/article/how-to-sound-design-a-youtube-video
- 업비트 「효과음 넣는 법」: 휙=전환·튀어나옴, 딸깍=화면 속 작은 동작, 톡=음악이 멈춘 자리. 「모든 컷에 소리가 필요하지 않다」 「차분한 영상에 오락실 소리 금지」 — https://uppbeat.io/blog/sound-effects/how-to-add-sound-effects-to-videos
- 에피데믹 사운드 「소리 섞기」: 효과음 -10~-20dB, 음악 -18~-22dB — https://www.epidemicsound.com/blog/audio-editing-techniques/
- 틸노트 「전환·시각 효과」: 효과를 뺐을 때 뜻이 덜 전달되지 않으면 그냥 컷. 흔들림은 놀람에 짧게, 글리치는 실수에 가끔, 확대는 잦으면 무엇이 중요한지 흐려짐 — https://tilnote.io/pages/6a114ad8254c64bd78f4ee74
- 오퍼스 「2026 편집 미감 11가지」: 한 영상 안에서 미감을 섞지 말고 2주는 한 가지로 — https://www.opus.pro/blog/editing-aesthetics-dominating-short-form-2026

## 전에는 이랬다 → 고친 것 (src/fx.ts 「효과 감독」)
| 전 | 문제 | 고친 것 |
|---|---|---|
| 자막이 바뀔 때마다 휙, 순서대로 돌려 씀 | 컷마다 소리 → 놀람이 없음, 뜻과 상관없는 소리 | 휙은 단계가 바뀔 때만, 2초 안에 또 넣지 않음. 차분·따뜻한 편은 휙 없음 |
| 휙을 컷 3프레임 앞에 일괄 배치 | 큰 순간이 컷과 어긋남 | 소리마다 가장 큰 순간을 재서 컷에 닿게 앞당김 |
| 결과 장면도 다른 장면과 같은 크기의 소리 | 가장 중요한 순간이 안 삶 | 결과 직전 배경음을 0.4초 내리고 → 낮은 쿵+반짝을 겹쳐 치고 → 배경음을 1초쯤 살짝 올림 |
| 배경음과 장면이 따로 놂 | 박자가 안 맞음 | 결과 장면이 마디 첫 박에 떨어지게 곡 시작 지점을 계산 |
| 모든 편에 같은 밈 외침 | 분위기와 안 맞음 | 분위기별 소리 묶음: 경쾌(쿵+반짝+환호) / 일상(톡+반짝+아하) / 차분(반짝만) / 긴장(라이저→낮은 붐, 8프레임 흔들림) / 따뜻(줄 튕김+반짝) |
| 화면 효과는 손 표시뿐 | 결과가 밋밋 | 결과 순간 4프레임 동안 3.5~7% 당겨 잡기. 흔들림은 사고·놀람 편에서만 |
| 누르는 소리가 효과음만큼 큼 | 화면 속 소리가 튐 | 누름·타자 소리는 작게(타자는 한 번 걸러) |

## 지키는 규칙
1. 넣기 전에 묻는다: 이 효과를 빼면 뜻이 덜 전달되는가? 아니면 뺀다.
2. 한 영상 안에서 소리 묶음과 미감은 한 가지.
3. 새 효과는 fx.ts 의 분위기 묶음에 더한다(장면 코드에 흩어 놓지 않는다).
