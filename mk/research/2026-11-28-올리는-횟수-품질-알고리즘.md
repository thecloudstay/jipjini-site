# 올리는 횟수·여러 채널 동시 올리기와 노출 알고리즘 (2026-11-28, 대표 「너무 자주·많이 올리면 품질지수 알고리즘 반영해서 짜는 거 맞지?」)

## 출처 (해외 중심)
- 비드아이큐 2026-07 조사(채널 1,020만 개): 한 달 12편 이상 올린 채널의 조회 증가율이 한 달 1편 미만의 4.1배. 많이 올려서 떨어지는 구간은 없었음. 단 상관관계이고 「안 볼 영상은 횟수로 못 메운다」 — https://vidiq.com/research/youtube-upload-frequency-study/
- 에어 미디어테크: 쇼츠 기본 주 3~5편, 하루 1편으로 시작해 늘리기, 「주 5편 8주 뒤 품질 유지될 때만 조정」. 위험은 ① 구독자 피로 ② 같은 소재 반복 → 새 시청자에게 덜 보여 줌 ③ 품질 희석 → 시청 유지 하락 → 노출 하락 — https://air.io/en/youtube-hacks/how-often-should-you-post-shorts-to-grow-faster
- 포스트브리지(각 플랫폼 공식 발표 정리): 내가 만든 영상을 여러 앱에 올리는 것 자체에 벌점 공지는 없음. 벌점 대상은 남의 영상 재게시와 다른 앱 워터마크. 인스타그램은 2026-04-30부터 30일 단위로 「주로 비독창 게시」 계정을 추천에서 뺌. 틱톡은 「새로운 것 없는 재사용」 추천 제외. 유튜브는 2026-10 독창 콘텐츠 우선 — https://www.post-bridge.com/blog/does-cross-posting-hurt-engagement
- 메타 페이스북 독창 크리에이터 보상(2026-03), 비독창 콘텐츠 단속 — https://creators.facebook.com/blog/combating-unoriginal-content

## 그래서 우리 자동 올리기 규칙
1. 횟수: 채널마다 하루 최대 1편, 주 3~5편으로 시작. 8주 동안 유지하고 지표 보고 조정.
2. 자동 감속: 노출 대비 조회·평균 시청 비율이 2주 연속 떨어지면 주 3편으로 줄이고 보고.
3. 같은 소재·형식 연달아 금지: 연속 2편이 같은 형식·같은 갈고리면 순서를 바꿈.
4. 여러 채널 동시: 워터마크 없는 원본 파일을 채널마다 따로 올림(틱톡 저장본 재사용 금지). 제목·설명·해시태그는 채널별로 다르게.
5. 독창성: 우리가 만든 영상만. 남의 영상 잘라 쓰기 없음(밈 효과음 짧게 쓰는 것은 별개).
6. 검수 통과 못 한 영상은 횟수 채우려고 올리지 않음.
