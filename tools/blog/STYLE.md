# 집지니 네이버 블로그 글 쓰는 법 (2026-11-17)

대상: blog.naver.com/cloudstay_ · 주 2편(화·금) · 발행은 대표가 붙여넣기로.
문체는 콘솔 저장소 blog/문체규칙.md 를 함께 지킨다(오프닝·구조·제목 로테이션, 직전 3글과 겹치지 않게 — blog/LOG.md).
본보기: tools/blog/example_post.json (래미안안양메가트리아 34평)

## 순서
1. `python3 tools/blog/blog_topics.py` → tools/blog/_facts.json (주제·숫자). 이 파일에 있는 숫자만 쓴다. 지어내지 않는다.
2. _facts.json 을 보고 tools/blog/_post.json 을 쓴다(아래 규칙).
3. `python3 tools/blog/blog_draft.py` → blog-draft/<글번호>/ 초안 쪽 + 그림, 대장 「초안」.
4. 글 쪽·대장을 main 에 올린다. 콘솔이 8시 넘어 텔레그램으로 대표에게 알린다.

## 글 종류 (2026-11-17 대표 「비용 해설보다 셀인·셀인대행 + 도면 자동화 + 30% 절감으로 다각화」)
번갈아 쓴다: 도면견적 ↔ 셀인대행 → 실견적 → 누수 → 경매
- 도면견적(중심): 「도면 한 장 → 물량(_facts 도면물량) → 실견적 단가 → 턴키 대비 절감(_facts 절감)」 3단계 이야기. 집지니 핵심 역량(도면 자동화·물량 산출)이 주인공.
- 셀인대행: 셀인 / 셀인대행(반셀프 인테리어) / 턴키를 그 단지 숫자로 비교하고 「누구에게 어느 쪽이 맞나」 기준을 준다.
- 실견적: 실제 보낸 견적을 줄마다. 누수·경매: 그 단지 도면으로 계산한 복구비·수리비.
- 절감은 _facts 「절감」의 실제 % 를 쓴다(공사비만 30%, 코디비까지 넣으면 그 값). 30% 를 지어내 붙이지 않는다.

## 제목
- 단지명 + 평수(공급평 반올림) + 핵심 검색어 + 금액. 예: 「래미안안양메가트리아 34평, 도면 한 장으로 셀인대행 견적 뽑아 보니 턴키보다 1,013만 원 적었습니다」
- 누수: 「○○아파트 누수 복구 비용, 천장만 젖으면 123만 원부터」 / 경매: 「○○ 경매 낙찰 전 수리비, 기본 수리 2,553만 원」 / 실견적: 「시흥 33평 실제 견적 2,679만 원, 줄마다 공개합니다」

## 본문 (블록 7~12개, 1,200~2,000자)
- 첫 문단에 답: 단지·평형·금액·부가세 10% 별도.
- 그림 2~3개: 도면 · 공사비 · 공종표(단지공사비) / 누수표(누수) / 경매표(경매) / 견적(실견적).
- 단지공사비 글에는 반드시 「셀인대행」 「반셀프 인테리어」(또는 반셀인) 를 넣고 턴키와 금액을 비교한다.
- 「공사 전에 먼저 볼 것」은 _facts 의 먼저볼곳을 대표 말로 다듬어 쓴다(연식·세대 수가 단지마다 달라 글이 겹치지 않게).
- 끝 문단: 다른 평형·누수·경매는 집지니 쪽에서, 정확한 견적은 무료 24시간.

## 말투·금지
- 「저희는 ~합니다」 운영자 말투. 짧은 문장, 숫자는 _facts 그대로.
- 금지: 이모지, 느낌표, 「혁신적인·완벽한·한눈에」, 「~가 아니라 ~입니다」 반복, 셋씩 묶은 나열, 영어 낱말.
- 집지니 누리집 쪽 글을 그대로 옮기지 않는다(네이버가 같은 글로 본다). 같은 숫자를 다른 문장으로.
- 고객 이름·전화·정확한 동호수는 쓰지 않는다.

## 태그 (8~10개)
단지명, 단지명+인테리어, 지역+아파트인테리어, 평수+올수리비용, 셀인대행, 반셀프인테리어, 반셀인, 아파트인테리어비용, 집지니 — 주제에 맞게(누수복구비용·경매수리비 등).
