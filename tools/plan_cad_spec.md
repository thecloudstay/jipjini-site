# 집지니 평면 자료 → 캐드 규격 (2026-11-12 정함)

대표 지시: 「데이터 사업을 위해 캐드화·캐드 기호가 호환되도록」. 설계사무소·시공사가 받아서 바로 쓰도록
층 이름은 미국 국가 캐드 표준(건축 분야 층 이름 규칙)의 틀을 따른다. 국내 건설 전산도면 표준도 같은 틀
(분야 글자 1자 + 주요소 4자 + 보조요소 4자)을 쓰므로 그대로 호환된다. 단위는 밀리미터, 원점은 건물 왼쪽 아래.

## 평면 자료(누리집·캐드·견적 공통 한 벌)
- 벽선: [방향, 시작, 끝, 중심선, 두께mm] — 그림 화소 좌표, 두께는 250/200/120 중 하나(종류를 뜻함)
- 문: 경첩(x1,y1) · 열리는 끝(x2,y2) · 문짝 끝(cx,cy)
- 샷시: [방향, x0, y0, x1, y1]
- 방: 다각형 · 이름 · 종류 · 면적
- 공용칸 · 승강기 범위
- mmpp(그림 1화소의 mm) 로 실제 크기로 바꾼다. y 는 위아래를 뒤집는다(캐드는 위가 +).

## 집지니 캐드 편집기 ↔ 캐드 파일 (2026-11-12 개편)

한 벌의 중립 도면 목록(assets/cad_io.js 의 model)을 거쳐 모든 형식이 오간다.

| 하는 일 | 형식 | 담당 |
|---|---|---|
| 저장 | 오토캐드 고유 형식(.dwg, 2018 판) | assets/cad_dwg.js — 공개 프로그램 acad-ts(MIT)를 묶은 것, 누를 때만 불러온다. 다시 묶기: tools/cad_dwg/build.sh |
| 저장 | 캐드 교환 파일(.dxf, 가장 오래된 판) | assets/cad_io.js writeDXF — 한글은 \U+XXXX |
| 저장 | 피디에프(A3 한 장)·사진(.jpg) | 집지니 도면 그림 → cad_io.js pdf(바깥 도구 없이 직접 짬) |
| 열기 | .dxf | cad_io.js parseDXF(기호 펼치기, 한글 풀기, 글자판 자동 판별) |
| 열기 | .dwg | cad_dwg.js read |
| 열기 뒤 | 집지니가 낸 파일 | 층(A-AREA·A-WALL-*)·기호(JJ-*)로 방·벽·문·창·승강기를 그대로 되살림(왕복 무손실 시험: 벽·문·창·방 개수 동일) |
| 열기 뒤 | 남의 도면 | 선을 그림으로 그려(벽 층은 채움) 집지니 그림 읽기에 넘기고, 축척은 캐드 단위로 바로잡음 |

검증: 고유 형식은 별도 읽기 프로그램(LibreDWG)으로 층·기호·속성·한글을 다시 읽어 확인했다.
