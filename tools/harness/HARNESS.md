# 도면 변환 자가 개선 고리 (하네스)

2026-11-12 대표 구상: 「받은 평면도를 우리 규칙으로 먼저 전부 빠르게 바꾸고 → 검수 로봇이 걸러 → 바로 고칠 수 있는 것만 고치고 → 고칠 수 없는 예외만 추려 클로드에게 보고 → 클로드가 배워 다시 적용 → 채점」.

## 한 바퀴

| 단계 | 하는 것 | 누가·무엇으로 |
|---|---|---|
| 1 방 읽기 | 원본마다 방·축척(누리집과 같은 길) | `node tools/harness/rooms.js` |
| 2 일괄 변환·검수·자동 고침·가르기·채점 | `pipeline.py` 한 번에. 축척을 못 읽으면 전용면적으로 정함 | 컴퓨터(토큰 없음) |
| 3 예외함 | 유형(규칙 번호·처음 보는 모양)별 묶음, 평면 수 많은 순, 대표 5곳 | `예외함.json`, `요약.txt` |
| 4 학습 | 예외함 1순위 유형의 대표 그림을 직접 보고 원인 확인 → 규칙부터 더하고(`plan_check.py`) → 원인 단계 고침(`plan_trace.py` / 자동 고침은 `pipeline.py` FIXERS) | 클로드 |
| 5 관문 | 같은 표본을 다시 돌려 견줌(`pipeline.as_result` → `run.py 관문 앞 뒤 고친규칙`). 안전 규칙(R5·R10)은 하나도 늘면 안 됨, 고친 규칙이 줄어야 함, 무게 합이 줄어야 함 | 컴퓨터 |
| 6 반영 | 남김: `apply.py` 로 누리집 자료·캐드 다시 만들기 → 합치기. 버림: 코드 되돌림 + 일지에 무엇을 해 봤고 왜 버렸는지 | 클로드 |

판정: **출고보류**(문 안전 R5·현관문 R10·외벽 R1·면적 R11 남음 — 고객에게 내보내지 않음) / **예외**(자동으로 못 고친 것·처음 보는 모양 3곳 넘음) / **통과**.
채점: 검수 규칙과 따로, 원본 그림 기준(100 − 벽 놓침% − 군더더기% − 2×원본과 다른 곳).
자동 고침(FIXERS): R9 벽 위 창 지우기 · R2 창을 벽 두께·중심선에 · R3 창 끝 붙이기 · R4 모서리 잇기 — 고친 뒤 무게가 줄고 안전 규칙이 늘지 않을 때만 씀.

`일지.md`: 판마다 한 줄 + 버린 시도의 내용(같은 시도를 되풀이하지 않게).
`알려진모양.json`: 모양 표식 → 규칙 번호 또는 「무시: 이유(날짜)」.

## 지킬 것
- 원본 평면도 그림은 저장소·합치기 요청·보고에 넣지 않는다(좌표·숫자만). 가져온 사본은 일이 끝나면 지운다.
- 관문을 통과하지 못한 고침은 합치지 않는다. 관문 기준을 느슨하게 고치지 않는다. 고친 뒤에 목표 규칙을 바꿔 다시 관문에 넣지 않는다.
- 규칙 셈이 틀린 것(실제 구멍이 아닌데 셈)은 고칠 수 있다 — 단, 잘라 본 그림으로 확인한 경우만, 일지에 적는다.
