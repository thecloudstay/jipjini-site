# 영상 자체 평가 체계 (2026-11-28 대표 「네가 만든 것 자체 평가·검증하도록 시스템 구성」)

만든 쪽이 스스로 「괜찮다」고 하는 것은 믿지 않는다. 세 단계를 차례로 거친다.

| 단계 | 누가 | 무엇을 | 결과 |
|---|---|---|---|
| 1. 기계 검사 | `check.py` | 길이·크기·음량·소리 깨짐·높은 음이 튀는 시각·어색한 정적·말이 알아들리는지(음성 인식)·금지 소리·표기·조사 문서 | 통과/수정/차단 + 시각 + 가장 작은 고칠 점 |
| 2. 눈 검사 | 검수 담당(jj-inspector), 만든 쪽과 다른 담당 | 장면표 그림을 `검수표.md` 로 판정(이유 먼저, 예/아니오) | 통과/수정/차단 |
| 3. 대표 판정 | 대표 | 보고 한마디 | `대표판정.jsonl` 에 쌓임 |

- 1단계 탈락은 2단계 「통과」보다 우선한다. 올리기(유튜브 등)는 1·2단계가 모두 통과일 때만 한다.
- 고치고 다시 검사는 2번까지. 그래도 안 되면 대표에게 보고하고 멈춘다.
- 대표가 지적한 것은 `대표판정.jsonl` 에 적고, **그 지적을 잡아낼 검사가 있는지** 확인한다. 없으면 `check.py` 나 `검수표.md` 에 항목을 더한다(같은 지적을 두 번 받지 않게).
- `python3 check.py --selftest`: 일부러 망친 영상 3개(높은 음·너무 큼·정적)가 탈락하는지 본다. 하나라도 통과하면 검사기가 고장 난 것이니 영상 검사 전에 고친다. 검사 묶음을 돌릴 때마다 먼저 돌린다.

## 준비
```
pip install sherpa-onnx numpy
curl -L -o zk.tar.bz2 https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-zipformer-korean-2024-06-24.tar.bz2 && tar xjf zk.tar.bz2
export JJ_ASR=$PWD/sherpa-onnx-zipformer-korean-2024-06-24/
```

## 아직 기계가 못 보는 것
- 소리가 「힙한지」 「중국풍인지」 같은 취향. 대표 판정으로만 알 수 있어 `대표판정.jsonl` 에 쌓는다.
- 그림체가 마음에 드는지. 새 그림체는 영상 전체를 만들기 전에 시험 컷부터 대표에게 보인다.
