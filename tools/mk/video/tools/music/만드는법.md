# 분위기별 배경음 직접 만들기 (2026-11-28 대표 「악기가 건반뿐이고 저품질 → 깃허브 소스 찾아 다시」)

- 악보: compose.py 가 미디 5곡을 쓴다(경쾌·일상 대화·차분·긴장·따뜻). 곡마다 악기 편성이 다르다.
- 연주: render.mjs 가 실제 악기 녹음 음색으로 소리 파일을 만든다.
  - 연주기: 스페사신스(깃허브 spessasus/spessasynth_core, 아파치 2.0)
  - 음색 모음: 제너럴유저 지에스(깃허브 mrbumpy409/GeneralUser-GS) — 「만든 음악은 개인·상업 모두 제한 없이 사용」
- 직접 만든 곡이라 유튜브·인스타·틱톡·네이버 어디에 올려도 된다.

```
mkdir -p /tmp/mus && cd /tmp/mus && npm i spessasynth_core generaluser && pip install mido
python3 <여기>/compose.py o && node <여기>/render.mjs node_modules/generaluser/GeneralUser.sf2 o/*.mid
for m in up talk calm tense warm; do ffmpeg -y -i o/mood_$m.wav -t 56 -af "highpass=f=35,equalizer=f=90:t=q:w=1:g=-2,lowpass=f=7500,acompressor=threshold=-18dB:ratio=2.5:attack=15:release=160,loudnorm=I=-16:TP=-1.5,afade=t=out:st=54:d=2" -ar 44100 ../../public/sfx/mood_$m.wav; done
```

| 곡 | 분위기 | 빠르기 | 편성 |
|---|---|---|---|
| mood_up | 경쾌 | 96 | 펑키한 재즈 힙합: 전기 건반 끊어치기, 전기 베이스, 808 북+손뼉, 뮤트 기타, 가락은 재즈 기타 → 뮤트 트럼펫 |
| mood_talk | 일상 대화 | 90 | 느긋한 붐뱁: 전기 건반, 통 베이스, 가락은 재즈 기타 → 피아노 |
| mood_calm | 차분 | 76 | 로파이: 굴리는 피아노 화음, 통 베이스, 테두리 치기, 가락은 나일론 기타 → 전기 건반 |
| mood_tense | 긴장 | 88 | 어두운 재즈 힙합: 길게 누른 전기 건반, 베이스 반복, 가락은 뮤트 트럼펫 → 낮은 피아노 |
| mood_warm | 따뜻 | 82 | 네오 소울: 전기 건반, 통 베이스, 가락은 테너 색소폰 → 재즈 기타 |

대표 지적(2026-11-28): 5음 음계 가락 + 마림바·현 뜯기·클라리넷은 「중국풍」으로 들린다 → 쓰지 않는다. 9도·13도 화음, 2-5-1 진행, 16분 스윙 북, 반음 접근 베이스로 짠다.

규칙: 한 곡은 한 묶음에 3편까지, 같은 곡을 쓰는 편은 시작 마디를 달리한다. 종소리·높은 소리 악기는 쓰지 않는다.
