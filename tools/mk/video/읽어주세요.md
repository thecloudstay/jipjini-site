# 집지니 쇼츠 영상 틀 (리모션)
2026-11-28 대표 「영상 구려 — 최신 트렌드 분석해서 따라 할 수 있어야지」 → 조사 결과대로 만든 첫 틀 「숫자 반전」(마티즈 편). 같은 날 「따로 논다 — 하나의 이야기로」 지시로 한 배경·한 색 규칙의 이야기형(견적서 → 헐 미친 → 줄 긋고 2,775만 → 1,189만 남음 → 동전이 차로 → 마티즈 샀다 긔긔 → 우리 집은 얼마?)으로 바꿈.

- 화면: 1080×1920 꽉 채움, 30프레임, 장면 0.7~2.5초, 장면 시작마다 줌 펀치
- 움직임: 단어 튀어나오기(스프링), 숫자 0→값 돌기, 쾅 찍히며 흔들림, 막대 경주, 주소 타자, 위쪽 진행 막대
- 소리: public/sfx — 케니(CC0) 효과음 + 자체 비트. 유명 밈 소리·남의 음악은 쓰지 않음
- 글꼴: tools/mk/fonts 의 woff2 를 public/ 에 복사해서 씀
- 만들기: npm i → npx remotion render src/index.ts Maru out.mp4 --concurrency=2
  (작업 컨테이너: --browser-executable=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell)
- 라이선스: 리모션은 개인·직원 3명 이하 회사 무료(상업 사용 포함). 직원이 늘면 회사 라이선스 확인.
