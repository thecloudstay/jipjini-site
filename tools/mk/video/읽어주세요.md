# 집지니 쇼츠 영상 틀 (리모션)
2026-11-28 대표 「영상 구려 — 최신 트렌드 분석해서 따라 할 수 있어야지」 → 조사 결과대로 만든 첫 틀 「숫자 반전」(마티즈 편). 같은 날 「따로 논다 — 하나의 이야기로」 지시로 한 배경·한 색 규칙의 이야기형으로 바꿈.

- 화면: 1080×1920 꽉 채움, 30프레임, 장면 0.7~2.5초, 장면 시작마다 줌 펀치
- 움직임: 단어 튀어나오기(스프링), 숫자 0→값 돌기, 쾅 찍히며 흔들림, 막대 경주, 주소 타자, 위쪽 진행 막대
- 소리: public/sfx — 케니(CC0) 효과음 + 자체 비트. 유명 밈 소리·남의 음악은 쓰지 않음
- 글꼴: tools/mk/fonts 의 woff2 를 public/ 에 복사해서 씀
- 만들기: npm i → npx remotion render src/index.ts Maru out.mp4 --concurrency=2
  (작업 컨테이너: --browser-executable=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell)
- 라이선스: 리모션은 개인·직원 3명 이하 회사 무료(상업 사용 포함). 직원이 늘면 회사 라이선스 확인.
- 다음 틀: 말풍선 대화 · 「아니 아니 아니… 이거!」 · 고지서 형광펜 · 구글 음성 나레이션 + 단어 자막

## 소리 (2026-11-28 판)
- 배경음 `music.wav`: 120BPM(박당 15프레임), 8마디 16초, 라단조 진행. 강조 직전 0.14초 비우고(드롭) 강조 때 낮춤(덕킹 −5dB).
- 강조·전환은 모두 박자 칸(`T`)에 맞춤. 전환 4프레임 전 휙 소리, 큰 숫자 공개 전 상승음(riser), 핵심 문장에 저음 쿵(boom).
- 마무리: 압축 → 리미터(−1.5dB) → 약 −14 LUFS(쇼츠·릴스 권장 크기).
- 배경음과 riser·boom은 numpy로 직접 합성(저작권 문제 없음). 효과음은 Kenney CC0.

## 소리 (v6, 2026-11-28 대표 「종소리 계속 들어가 짜증남 · 이펙트 다양하게」)
- 배경음에서 종소리처럼 울리던 사인파 아르페지오를 빼고, 808 베이스와 오프비트 코드 찍기(톱니파+저역통과)로 바꿈. `tools/synth.py` 로 다시 만듦.
- 효과음 규칙: 장면 뜻마다 다른 소리 하나, 같은 소리 되풀이 금지(타자음만 3가지를 번갈아).
  견적서 등장=종이 밀기 · 「?」=레코드 긁힘+쿵 · 단지 입력=타자 · 줄 긋기=펜 · 새 금액=펀치+반짝 · 돈 날아감=칩 소리 · 큰 숫자=808 떨어짐 · 자동차=경적 · 마티즈=에어혼 · 긔긔=띠용 · 마무리 전환=테이프 멈춤 · 「얼마?」=쿵+뿅 올라감 · 주소=타자.
- 유명 밈 원본 소리는 쓰지 않고, 같은 느낌을 직접 합성(에어혼·띠용·레코드 긁힘). 나머지는 케니 CC0.
