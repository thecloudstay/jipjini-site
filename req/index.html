  5. 처음이라면 「전체 리모델링」과 「모두 상담 후 결정」 두 가지만 체크하고 제출하셔도 됩니다.

    ② 평면도 넣기

    분양 안내문, 네이버 부동산·부동산114 화면 캡처, 종이 도면을 찍은 사진 모두 됩니다. 방 이름과 치수 숫자를 읽고 방을 나눠 방별 크기를 채웁니다. 없으면 건너뛰셔도 됩니다.

    방·욕실 수가 다르면 고쳐 주세요 — 방 욕실
    도면에서 방을 정확히 나누지 못해, 같은 방·욕실 수의 보통 구성(실제 평면 통계)으로 어림했습니다. 올린 도면은 코디가 직접 확인합니다.
    전용면적을 알면 방별 가로·세로까지 계산합니다. ①에서 찾거나 아래 건물 정보에 적은 뒤 도면을 다시 넣어 주세요.
    부동산 사이트에서 보던 우리 단지 주소(링크)가 있으면 붙여 넣어 주세요. 코디가 바로 열어 봅니다.

    ③ 도면이 없다면 — 비슷한 평면 고르기

    예시 평면을 준비하고 있습니다. 방·욕실 수만 알려 주셔도 보통 구성으로 어림합니다 — 아래 건물 정보에서 전용면적을 적어 주세요.

    ① 어떤 공사를 원하시나요? (카테고리 클릭 → 펼침)

    인테리어가 처음이세요? 천천히 따라 하세요

    1단계. 선택하신 공사 옆 [▶ 세부] 버튼을 눌러주세요. 자재와 측정 입력칸이 펼쳐집니다.
    2단계. 원하시는 자재를 체크하시고, 측정값(가로·세로·갯수)을 적어주세요.
    3단계. 자재나 측정값이 어렵게 느껴지시면 "상담 후 결정"만 체크하세요. 집지니의 코디(Codi)가 카톡으로 친절히 도와드립니다.
    4단계. 측정값을 비워두셔도 괜찮습니다. 평형 기준 평균값으로 자동 산정하고, 정확한 수치는 집지니의 코디(Codi)가 카톡 상담 시 확정해드립니다.

    가장 쉬운 방법: 위쪽 "전체 리모델링(올수리)" + "모두 상담 후 결정" 두 가지만 체크하시고 제출하시면, 집지니의 코디(Codi)가 카톡으로 처음부터 끝까지 친절히 안내해드립니다.

    ② 공사별 세부 입력 (옛 — 인라인 통합됨)
    인테리어 처음이세요? "상담 후 추천" 그대로 두면 집지니의 코디(Codi)가 카톡으로 자재 모델·자재상을 직접 추천드립니다.
    측정값 (가로·세로·갯수)은 ③ 자재 아코디언 안에 work별로 자동 표시. 모르면 비워두고 제출하셔도 집지니의 코디(Codi)가 카톡 상담드려요.
    방별 측정 — 가로 × 세로 (도배 벽면적 + 몰딩 둘레 자동)

    각 방의 가로 × 세로 입력하시면 도배 벽 면적 + 몰딩·걸레받이 둘레가 자동 계산됩니다. (창호·문 차감은 코디 현장 측정)

    합계: 방 개 / 총 벽 면적 ㎡ / 총 몰딩 둘레 m
    창호 측정 — 창별 가로 × 세로 (자동 면적 합산)

    외창 1개씩 가로 × 세로 입력 → 자동 자²/㎡ 합산. 등급(보급/중급/프리미엄)은 위 ② 공종에서 선택. 모르면 코디 현장 측정.

    합계: 창 개 / 총 면적 ㎡
    베란다 측정 — 가로 × 세로 (확장·도장·단열 자동)

    베란다별 가로 × 세로 + 도장/단열 면적 (자²). 박 대표 spec: 도장은 베란다만.

    욕실 측정 — 가로 × 세로 (벽 + 바닥 타일 자동)

    각 욕실 가로 × 세로 입력 시 벽(둘레×2.4 - 문) + 바닥(가로×세로) 자동 합산 → 견적서 반영

    합계: 욕실 개 / 총 타일 면적 ㎡

    방·거실 합산 실 바닥면적 (천장 높이 2.4m 통일)

    안내: 평수 (1평 = 3.3㎡) × 0.8 = 전용면적 근사값. 예: 32평 → 약 84㎡
    모르면 비워두고 제출 → 집지니의 코디(Codi)가 평수 기반 자동 산출 후 카톡 안내드립니다.
