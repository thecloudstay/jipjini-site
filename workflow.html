HOW IT WORKS

비교부터 입주까지 11단계

각 단계를 누르면 상세 내용이 펼쳐집니다. 정식 견적서는 단 3만원.

1방식 비교 · 검토무료
턴키·직영·코디 세 방식을 비교합니다. 내 의뢰가 코디에 맞는지(부분 수리 3개 이상) 확인하는 단계입니다. 1~2개 단일 공정은 직영이 유리하니 정직하게 안내드립니다.
일반 턴키일단 계약부터 권유
집지니안 맞으면 직영을 권하며 거절
2코디 선택 · 무료 가안 신청무료
홈페이지 폼에서 평형·공정·등급을 입력하면 실시간 예상 견적이 즉시 나옵니다. 신청하시면 코디가 가안을 작성해 카톡으로 보내드립니다 (영업일 2~3일).
일반 턴키상담받아야 대략 금액 안내
집지니신청 전에도 실시간 금액 확인
3정식 견적서 신청 · 3만원토스페이먼츠
박찬영 대표가 직접 작성하는 정식 코디 견적서를 받으시려면 3만원만 결제합니다. 진행을 결정하시면 이 3만원은 코디 비용에서 그대로 차감됩니다. 진입 부담을 낮추고, 진성 의뢰만 받기 위한 최소 절차입니다.
일반 턴키견적은 공짜, 대신 계약 압박
집지니3만원, 대신 진행 시 전액 차감
4정식 코디 견적서 수령상세 공개
자재 모델명·규격, 매칭 자재상·기술자, 공정별 단가까지 100% 공개된 진짜 견적서를 받습니다. 무료 가안의 흐릿한 추정치와 달리, 실제로 시공 가능한 확정 견적입니다.
일반 턴키자재 브랜드·원가 비공개
집지니모델명·단가 100% 공개
5본견적 검토 · 진행 결정고객 판단
정식 견적서를 받아보고 이 방식이 마음에 들면 진행합니다. 자재 등급·옵션은 여행사 패키지처럼 자유롭게 바꿀 수 있습니다. 진행 안 하셔도 부담 없습니다.
일반 턴키업체가 정한 사양 위주
집지니등급·옵션을 직접 선택
6코디 비용 결제 · 전자계약토스페이먼츠
진행을 결정하시면 코디 비용을 결제하고 전자계약을 체결합니다. 먼저 낸 3만원은 코디 비용에서 차감됩니다. (PM을 추가하셨다면 PM 비용도 이때 포함) 토스페이먼츠로 안전하게 결제됩니다.
일반 턴키공사비에 마진이 섞여 결제
집지니코디 운영비만 결제 (마진 0)
7단톡방 · 노션 페이지 초대협업 시작
건축주·코디·PM이 함께하는 카카오톡 그룹방을 개설하고, 진행 상황이 실시간 기록되는 노션 페이지에 초대합니다. 모든 과정이 추적 가능합니다.
일반 턴키전화·구두로 진행, 기록 없음
집지니단톡방·노션에 전 과정 기록
8자재 매칭 · 코디표 확정코디
코디가 검증된 자재상·기술자를 매칭하고, 공정별 자재·단가가 담긴 코디표를 확정합니다. 자재상과 미리 도매가(대리점 납품가)를 협상해 두기 때문에, 시중가보다 낮은 가격에 자재를 받으실 수 있습니다.
일반 턴키업체 거래처에 일임
집지니검증된 자재상, 단가 사전 협상
9자재 발주 · 픽업직거래
코디표대로 자재를 발주합니다. 인터넷 주문은 PM이 대행하고, 타일·도기 등은 직접 방문 확인. 모든 영수증·계약은 건축주 명의로 직거래됩니다. 집지니는 자재비를 받지 않습니다.
일반 턴키업체가 자재 구매·마진 포함
집지니건축주 명의 직거래, 마진 0
10시공 시작 · 현장 관리시공
시공이 시작되면 현장 관리가 필요합니다. 직접 하시는 경우, 집지니 코디가 미리 잡아둔 공정 순서·자재·일정표를 따라 진행하시면 됩니다. PM을 파견받으신 경우, PM이 중요한 공정에 직접 나가 챙기고 매일 카톡으로 사진과 함께 진행 상황을 보고드립니다. 자재비·인건비는 자재상·기술자에게 직접 결제하시면 됩니다. 시공 하자에 대한 보증은 실제 시공한 기술자와 자재를 공급한 자재상에게 있습니다.
일반 턴키현장 안 보이고 결과만 통보
집지니매일 보고 + 책임 명확
11입주 · 6개월 A/S · 추가 서비스A/S 포함
하자 점검 후 입주, 6개월 통합 A/S를 제공합니다. 코디·PM이 책임 기술자 호출을 코디네이팅합니다.
추가로 제공 가능한 서비스 엘리베이터 보양 (이사·운반 시 보호막 설치) 잔손 마무리 양중 (무거운 자재를 위층으로 올리는 작업) 입주 청소 이사 패키지

상담은 어떻게 하나요?
기본은 온라인·비대면 유선 상담입니다. 카카오톡 채널(@집지니)과 전화로 평면도·사진을 받아 견적을 진행합니다. 현장 방문은 계약 이후 필요한 경우에만 합니다. 대표님의 시간도, 고객님의 시간도 아끼는 방식입니다.
샘플은 직접 볼 수 있나요?
타일·도기·가구 등 실물 샘플은 거래처 쇼룸·매장에서 직접 보실 수 있습니다 (코디가 위치·방문 시간을 안내해 드립니다). 매장 방문이 어려우신 경우, 원하는 샘플을 택배로 보내드리고 회수하는 방식도 가능합니다.
