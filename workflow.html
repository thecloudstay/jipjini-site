HOW IT WORKS

비교부터 입주까지 8단계

각 단계를 누르면 상세 내용이 펼쳐집니다. 정찰제 · 마진 0% · 자동 견적서 무료.

1방식 비교 · 검토무료
턴키·직영·코디 세 방식을 비교합니다. 내 의뢰가 코디에 맞는지(부분 수리 3개 이상) 확인하는 단계입니다. 1~2개 단일 공정은 직영이 유리하니 정직하게 안내드립니다.
일반 턴키일단 계약부터 권유
집지니안 맞으면 직영을 권하며 거절
2정밀 의뢰서 작성5분 · 무료
공간별 가로·세로 실측 + 16공종 시공 의향까지 한 번에 입력합니다. 정확한 입력 = 정확한 견적. 자재는 표준(중급) 단일 정찰제로 통일되어 등급 선택 단계가 없습니다.
일반 턴키상담받아야 대략 금액 안내
집지니5분 입력 → 즉시 자동 견적 산출 시작
3자동 견적서 수령24시간 내
집지니의 코디(Codi)가 검토·확정한 견적서를 24시간 내 카카오톡으로 받으시면 자재 모델명·규격, 매칭 자재상·기술자, 공정별 단가까지 100% 공개됩니다. 별도 결제 단계 없이 무료입니다.
일반 턴키자재 브랜드·원가 비공개
집지니모델명·단가 100% 공개
4자재상·기술자 매칭코디
코디가 검증된 자재상·기술자를 매칭하고, 공정별 자재·단가가 담긴 코디표를 확정합니다. 자재상과 미리 도매가(대리점 납품가)를 협상해 두기 때문에, 시중가보다 낮은 가격에 자재를 받으실 수 있습니다. 모든 영수증·계약은 건축주 명의로 직거래됩니다.
일반 턴키업체 거래처에 일임 · 마진 포함
집지니검증된 자재상, 단가 사전 협상 · 마진 0
5전자계약 + 코디비·PM비 선불 결제네이버 스마트스토어
진행을 결정하시면 코디비·PM비 모두 시공 시작 전 100% 선불 결제하고 전자계약을 체결합니다. 자재비·인건비는 결제 대상이 아닙니다 (시공 시 자재상·기술자에게 직접). 네이버 스마트스토어(네이버페이)로 안전하게 결제되며, 카드·가상계좌·에스크로(안전거래)가 자동 적용됩니다. 미진행 시 코디비 전액 환불 · PM비는 작업 전 100%, 작업 후 진행분 차감 환불.
일반 턴키공사비에 마진이 섞여 결제
집지니코디비·PM비만 결제 (마진 0)
6시공 시작 + 간트차트 공유 URL시공·투명
시공 시작과 함께 고객 전용 간트차트 공유 URL이 발급됩니다. 카카오톡으로 받아 모바일에서 바로 열어, 사이트 일정·공정별 시작/종료·진행도를 실시간으로 확인하실 수 있습니다. 자재비·인건비는 자재상·기술자에게 직접 결제하시면 됩니다.
일반 턴키전화·구두로 진행 · 기록 없음
집지니간트차트 URL 한 번 클릭으로 전 일정 확인
7PM 관리 (선택)선택
직접 PM 하시면 비용이 가장 적게 듭니다. 집지니 코디가 미리 잡아둔 공정 순서·자재·일정표대로 진행하시면 됩니다. 시간·경험이 부담되시면 관리대리인 선임(집지니 PM)을 선택하세요. PM은 집중·간헐·원격 3단계로 차등 관리하며, PM 1인당 동시 3건까지만 받아 관리 품질을 지킵니다.
일반 턴키PM 5~10건 · 하자 대응 불가
집지니PM 3건 맥스 · 사고 시 즉시 대응
8입주 · 12개월 A/SA/S 포함
하자 점검 후 입주 — 집지니 하자 조율 약속이 시작됩니다. 책임은 시공한 기술자·자재상이, 해결 조율(접수·기술자 호출·재시공 일정)은 코디가 끝까지 무상으로. 12개월 집중 지원 + 이후에도 조율은 계속됩니다.
추가로 제공 가능한 서비스 엘리베이터 보양 (이사·운반 시 보호막 설치) 잔손 마무리 양중 (무거운 자재를 위층으로 올리는 작업) 입주 청소 이사 패키지

PM NECESSITY GUIDE

현장 관리(PM)는
원래 집주인인 당신의 몫입니다

직영 인테리어에서 현장을 챙기는 일은 본래 건축주의 역할입니다. 직접 하시면 비용이 가장 적게 듭니다. 시간·경험이 부담되시면, 그때 집지니가 PM을 파견해 도와드립니다.

의뢰 범위예상 시공총액집지니 코디PM
1개 공정 (도배만/장판만)~500만직영 권장불필요
2개 공정 (도배+장판)500~1,000만직영 권장불필요
3개 공정부터 (도배+장판+욕실)1,000~2,500만✔선택
복합 공간 (욕실+주방+도어 등)2,000~3,500만✔선택
올수리 (집 전체 인테리어)3,500만~✔권장

5초 자가 진단 — 평일 낮 시간을 자유롭게 못 내거나, 시공 경험이 처음이거나, 자재 검수·하자 판단이 자신 없거나, 본업이 바빠 현장에 못 가거나, 분쟁 시 직접 대응이 부담스러우시면 (3개 이상 해당 시) 관리대리인 선임(집지니 PM)을 고려해 보세요. 해당이 적으면 직접 PM이 가장 저렴합니다.

집지니 PM은 1인당 동시 3건까지만 맡아, 집중(주 4-5회)·간헐(주 2-3회)·원격 3단계로 차등 관리합니다.

PROCUREMENT GUIDE

자재는 어디서 사야 하나?

72%는 인터넷, 28%는 직접 방문. 반차 1-2일이면 충분합니다.

인터넷 주문 → 현장 배송 72%

구조목·석고보드·단열재 (목재상 온라인) · 도배지·필름 (개나리·LG 공식몰) · 바닥재 (LX하우시스 직거래) · 조명 (코웰·필립스 공식몰) · 스위치·콘센트·도어락 (전기자재상) · 주방가구 (한샘 상담 → 인터넷 발주) · 손잡이 (헤펠레·블룸 공식 수입사)

코디표대로 발주 처리. 영수증은 건축주 명의.

직접 방문 필수 28%

타일 (쇼룸에서 색감·질감 실물 확인) · 변기·세면대 (사이즈·사용감 확인) · 주방가구 (매장 1회 상담) · 도어 (컬러·재질 실물 확인) · 포인트 가구

총 방문 2-3회 (반나절씩). 코디 동행 또는 사전 화면 공유 상담. 매장 방문이 어려우면 샘플 택배 발송·회수도 가능합니다.

상담은 기본 온라인·비대면입니다. 카카오톡 채널(@집지니)과 전화로 평면도·사진을 받아 견적을 진행하며, 현장 방문은 계약 이후 필요한 경우에만 합니다.
